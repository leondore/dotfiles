# Agent skills installed with the skills CLI (github.com/vercel-labs/skills), globally:
# into ~/.agents/skills (Codex, opencode) and linked into ~/.claude/skills (Claude Code).
#
#   <source>                    every skill in the repo; skipped once any of them is installed
#   <source> <skill>            just that skill (its frontmatter name; `skills add <source> --list`)
#   <source> <skill> <new-name> that skill, renamed, e.g. when two sources ship the same name
#
# Sources are GitHub owner/repo (or a github.com URL). `skills update -g` updates them all,
# renamed ones included.
