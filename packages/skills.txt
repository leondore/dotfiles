# Global agent skills installed by install.sh into ~/.agents/skills (Codex, opencode),
# symlinked into ~/.claude/skills (Claude Code, Grok Build) and ~/.gemini/config/skills
# (Antigravity CLI, plus T3 Code's isolated Antigravity via config/skills symlink).
#
# Prefixed packs (installed & internal cross-references rewritten by sync-skill-packs):
#   <source> prefix:<pfx> [plugin]
#     `plugin` reads .claude-plugin/plugin.json instead of scanning every subdirectory.
#     Update with `sync-skill-packs` (use `--diff` to inspect rewrites).
#
# Plain skills (installed via the skills CLI, github.com/vercel-labs/skills):
#   <source>                    every skill in the repo; skipped once any of them is installed
#   <source> <skill>            just that skill (its frontmatter name; `skills add <source> --list`)
#   <source> <skill> <new-name> that skill, renamed, e.g. when two sources ship the same name
#     Update with `skills update -g`.
#
# Any line can end in only:<profile> or only:<tool> to install it only on that profile
# (personal, work) or when that tool is in TOOLS (see install.sh).
#
# Optional per-project / per-VM skills live in packages/optional-skills.txt (run `pick-skills`).
