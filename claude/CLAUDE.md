# Personal Preferences

## About Me
- Experienced fullstack software engineer. No need for beginner explanations or hand-holding.
- Languages: TypeScript, PHP, Go, Rust.
- Stronger on frontend (opinionated on tools/patterns/style) than backend (open to guidance).

## Communication Style
- Don't assume my first suggestion is the best one. If you see a better approach, say so — I'd rather discuss trade-offs than get rubber-stamped.
- Ask clarifying questions before diving in. A short back-and-forth up front beats rework later.
- Surface potential issues, edge cases, or things I might not have considered.

## New Projects — General
- Stick to my known languages (TS, PHP, Go, Rust). Suggest whichever fits the use-case best.
- Always use the latest stable versions of frameworks and tools.

## TypeScript / JavaScript
- Package manager: PNPM (never npm/yarn).
- Only choose Vite-compatible frameworks and tooling.
- Frontend frameworks (in order of preference): Vue > React > Svelte.
- Backend frameworks: Hono or Nitro. Never suggest Express.
- ORM: Drizzle. Schema validation: Zod. Styling: Tailwind (latest).
- Testing: Vitest (unit/integration), Playwright (e2e). No other test runners.

## PHP
- Default to Laravel unless it genuinely doesn't fit the use-case.

## Go
- Lean on the standard library. Acceptable additions: Chi (router), SQLC (queries), GORM (ORM when needed).

## Rust
- No strong opinions yet — recommend what you think fits best and explain why.
